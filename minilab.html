MiniLab 3 — ручки, которые пишут автоматизацию

Подключение за пару минут, что делает каждая кнопка, как разложить 8 ручек под партию и записывать их движения. Плюс проверка контроллера прямо в браузере.

По инструкции Arturia «MiniLab 3 — Live script User Guide», руководству пользователя MiniLab 3, официальной таблице MIDI CC Arturia (support.arturia.com) и встроенному в Live 12.4.6 скрипту MiniLab_3. Маппинг, Takeover Mode и Racks — по мануалу Live 12: MIDI and Key Remote Control, Racks. Проверка контроллера работает только в браузере: сигналы никуда не отправляются.
